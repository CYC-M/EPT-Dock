# EPT-Dock

EPT-Dock is a peptide–target binding evaluation and interpretation engine based on entropy-priced transport docking.

This repository contains **source code only**. Experimental data, PDB structures, generated results, logs, reports, literature, design documents, and manuscript materials are intentionally excluded.

## Contents

- `code/`: Python implementation and experiment entry points.

## Requirements

- Python 3.13+
- NumPy

Several entry points expect PDB inputs and calibration files supplied separately. The repository does not redistribute those data files.
